# 🕹️ Game AI: Prison Dodgeball

A simulation-based AI project where agents represent a **Prison Dodgeball Team**, each controlled using **Finite State Machines (FSMs)** to simulate strategic gameplay behavior. This project focuses on designing AI agents for a simplified Prison Dodgeball game. Each agent behaves autonomously based on its current state, environment inputs, and internal logic defined through a **Finite State Machine**. The goal is to model intelligent behaviors such as:

- Dodging incoming balls
- Throwing at opponents
- Collecting balls
- Rescuing teammates from "prison"
